基础语法：
1.SQL语句可以单行或者多行书写，以分号（;）结尾。
2.SQL语句可以使用空格/缩进来增强语句的可读性。
3.MYSQL数据库的SQL语句不区分大小写。
4.单行注释用#或--，多行用/* */
5.「MySQL 中，只要空格不破坏关键字、不省略关键字与字符串的分隔，就完全没影响；多余空格 / 换行随便加，不报错。」

MySQL 括号 () 核心作用笔记：

一、改变运算 / 逻辑优先级（最常用）
强制优先执行括号内内容，覆盖默认运算顺序
数学：(2+3)*4 先算加法
逻辑：A AND (B OR C) 先判断括号内条件
二、函数调用（强制语法）
所有函数必须带括号，无参数也要写
示例：NOW()、COUNT(id)、UPPER(name)
三、IN / NOT IN 列表
多个值必须用括号包裹
示例：age IN (18,20,22)
四、子查询（强制语法）
嵌套查询必须放在括号中
示例：WHERE id = (SELECT ...)
五、表达式分组 / 可读性优化
把复杂计算包成整体
示例：(price * num) AS total
六、建表 / 字段定义
包裹所有字段与约束：CREATE TABLE t(...)
指定长度：VARCHAR(50)
定义约束：CHECK(age>0)
